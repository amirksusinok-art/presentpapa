# Подарок для папы 🎁

Красивый поздравительный интерактивный сайт ко дню рождения папы с реалистичной 3D-подарочной коробкой, плавной кинематографичной анимацией открытия, душевным поздравлением, семейными фотографиями и финальным экраном «Мы тебя любим!».

## ✨ Особенности проекта

1. **Реалистичная 3D-коробка (Three.js):**
   - Настоящая трёхмерная геометрия коробки, крышки, атласной ленты и банта.
   - Студийное освещение с мягкими тенями и тёплым золотистым акцентом.
   - Плавная кинематографичная анимация открытия (5–8 секунд):
     - Камера мягко приближается.
     - Развязываются концы ленты и бант.
     - Крышка плавно приподнимается и отходит назад и вбок.
     - Изнутри вспыхивает мягкий золотистый свет и поднимаются мерцающие частицы.
     - Камера возвращается в удобный ракурс, открывая поздравительный блок.
2. **Тёплое поздравление:**
   - Появляется плавно на фоне открытой сияющей коробки.
   - Кнопка перехода к семейным воспоминаниям.
3. **Галерея семейных фотографий:**
   - Включены 14 уникальных семейных снимков (все дубликаты автоматически отфильтрованы).
   - Сетка с плавной загрузкой и скелетонами.
   - Полноэкранный просмотр (Lightbox) с поддержкой:
     - Стрелок и кнопок на экране.
     - Клавиш клавиатуры (`Left`, `Right`, `Escape`).
     - Сенсорных свайпов влево/вправо и свайпа вниз для закрытия на телефонах.
4. **Финальный экран «Мы тебя любим!»:**
   - Тёплые слова от всей семьи.
   - Кнопки для повторного просмотра фотографий или повтора всей анимации.
5. **Звуковое сопровождение (Web Audio API):**
   - Тёплые гармоничные аккорды и хрустальный перезвон при открытии коробки.
   - Полная независимость от внешних файлов (нет риска сбоя 404).
   - Кнопка включения/отключения звука в правом верхнем углу.
   - Корректная обработка политик автовоспроизведения браузера.
6. **Надёжность и адаптивность:**
   - Идеально оптимизирован для мобильных телефонов (поддержка safe areas, 100dvh).
   - **WebGL Fallback:** если на устройстве пользователя не поддерживается 3D WebGL, сайт автоматически переключается на стильный CSS 3D подарок, исключая белый/пустой экран.
   - Обработка ошибок загрузки изображений с аккуратными плейсхолдерами.

## 🚀 Локальный запуск и разработка

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки
npm run dev

# 3. Сборка для публикации
npm run build
```

## 🌐 Как опубликовать сайт на Render (Бесплатно)

Сайт полностью подготовлен к деплою на [Render](https://render.com).

### Способ: Static Site (Рекомендуемый, 100% бесплатно)
1. Зайдите в панель управления [Render Dashboard](https://dashboard.render.com).
2. Нажмите синюю кнопку **New +** в правом верхнем углу и выберите **Static Site**.
3. Подключите ваш GitHub аккаунт и выберите репозиторий `presentpapa`.
4. Заполните параметры (или оставьте значения по умолчанию):
   - **Name:** `presentpapa` (или любое желаемое имя)
   - **Branch:** `main`
   - **Build Command:** `npm run build`
   - **Publish Directory:** `dist`
5. Нажмите **Create Static Site**.
6. Через 30-40 секунд сайт будет собран и получит бесплатный адрес с SSL-сертификатом вида `https://presentpapa.onrender.com`.
